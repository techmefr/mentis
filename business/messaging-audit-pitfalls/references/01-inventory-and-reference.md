# messaging-audit-pitfalls §1 — Inventory and reference surface

Before anything is rewritten, find out what is out there and what it says. `business/product-marketing` §1
holds the four positioning sentences; this block is what you run first when words already exist.

## 1.1 Why audit before rewriting
1. **Inherited language is the main source of drift**, and you need to know what you are inheriting
   (chrisrodde positioning skill, audit mode).
2. **A rewrite that does not name what went wrong repeats it** with fresher adjectives (same source).
3. **The audit produces evidence.** "Three decks claim X and the newest says not to" moves a team in a
   way "the messaging is unclear" does not (same source).
4. **Own guidance:** if nothing exists yet, there is nothing to audit; use `business/product-marketing`
   §1 instead.

## 1.2 The inventory
Read everything before judging anything. Gather, with the date of each:
1. **The homepage and key product pages** (chrisrodde), plus the pricing page (pmalliance).
2. **Every deck in circulation**, with last-modified dates.
3. **Any messaging framework, positioning document or brand guide.**
4. **Recent sales collateral and one-pagers**, plus **customer-facing security or compliance summaries**.
5. **Recent customer calls or demo recordings**, if available (chrisrodde, audit inventory). The
   pmalliance consistency skill adds emails and nurture copy, paid and social ad copy, and product copy
   and onboarding where relevant.
6. **Record the date of each.** Vintage explains most contradictions: a stale document is a different
   problem with a different fix (chrisrodde). Own guidance: also record who last edited it and whether it
   is still sent to customers; a dead deck is a footnote, a live one is the finding.

## 1.3 Choose the reference surface
1. **State the reference.** Either an approved messaging framework, or, with none, the current homepage
   as the de facto source of truth, and say which you used (pmalliance message-consistency-check).
2. **Capture, per surface, how it renders the core message**: category, primary value, target audience,
   top three claims and the proof used (same skill).
3. **Compare across all surfaces**, logging every place a surface diverges from the reference or from the
   others.
4. **Comparing one surface to the reference at a time is a fallback**: slower, and it can miss a mismatch
   between two non-reference surfaces (the same skill's note on its fallback). Put everything side by side
   when you can.
5. **When two surfaces differ, show both versions** rather than deciding which is correct, unless the
   reference framework settles it (same skill).

## 1.4 The evidence standard
1. **Quote the exact wording from each surface involved and name the surface** (pmalliance).
2. **Never report a mismatch you cannot show with the actual copy.**
3. **Rate each mismatch by how visible the surface is and how central the divergent element is**, and
   explain the rating in one line rather than asserting it.
4. **Be specific about which artefact says what.** "Nine decks carry the absolute version of this claim"
   can be acted on; "the messaging is inconsistent" cannot (chrisrodde, presenting findings).

## Rewrite notes
**An opt-in mode.** The source is a mode that the user enters by agreeing to an offer. This block keeps that
property in every rule, and adds one line of own guidance: never gate real work behind an exercise (§1.3).

**Examples, not rules.** Ten to fifteen minutes, two exercises per session and the phrases quoted as
examples are the author's defaults.

## Removed
1. **The orientation mode** (`orient` argument, the lookup of an orientation file in four locations and the

2. **The plugin packaging and install paths** for two assistants.
3. **All learning-science claims and study references.** Only the headings of PRINCIPLES.md were read, so none
   is restated and no figure is carried.

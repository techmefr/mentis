# testing-blocks §5 — Keep what the runs taught as a table

> Section 5 of `skills/testing-blocks`. Read it when a block has been run under pressure and the recorded sentences have to be kept. The other sections and the guardrails stay in `SKILL.md`.

1. **The rationalisations recorded in step 1 become a two-column table inside the block**: the excuse, word
   for word, and the counter that answered it in the GREEN run. The table is built from the verbatim
   sentences of real runs. A table written from what an author predicts the agent will say is a guess, and
   the block states that it is one until a run replaces it.
2. **A short list of tells goes with it**: the thoughts that signal the drift ("just this once", "it should
   work now", "this case is obviously different") and the instruction to return to the start of the block
   when one appears. The list is also drawn from the recorded sentences.
3. **A row nobody ever produced is removed.** The table is evidence of what happened, not a catalogue of
   what could; a long table of unproduced excuses dilutes the real ones.

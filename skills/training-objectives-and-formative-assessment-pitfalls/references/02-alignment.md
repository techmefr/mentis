# training-objectives-and-formative-assessment-pitfalls §2 — Alignment

Each objective needs something to practise it and something to check it, at the same level of action. The
idstack skill calls this a bidirectional check; the wording below is a paraphrase.

## 2.1 Two passes
1. **Forward, objective to activity**: does the activity let learners practise the action the objective
   names? A "judge" objective with a "read the chapter" activity does not.
2. **Backward, objective to assessment**: does the assessment measure that action? idstack's example: a
   multiple-choice quiz mostly measures recognition and recall, so it does not assess "create"; a project,
   design or prototype does.
3. **Passive activities cannot prepare learners for active objectives** (idstack).

## 2.2 Gaps and mismatches
1. **Objective with no activity**: learners cannot practise it before they are checked.
2. **Objective with no assessment**: no one can know whether it was met; add one, or remove the objective if
   it is not needed.
3. **Activity with no objective**: either an objective is missing or the activity does not serve the course;
   add the objective or drop the activity.
4. **Mismatch**: activity or assessment at a different level from the objective.
5. **Show them in one table** with a status per row (aligned, mismatch, gap) so the gaps are the first thing
   a reviewer sees (idstack). Own guidance: review the table before any slides are made.

## 2.3 Where the check fits
1. **Each objective names a point in the session where it should be reached**; that point is where a
   checkpoint belongs (Carpentries, §3.1).
2. **Informing the learner matters too**: the Carpentries episode says that knowing an objective was met is
   motivating and supports learners monitoring their own progress.

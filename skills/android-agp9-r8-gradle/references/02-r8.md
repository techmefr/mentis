# android-agp9-r8-gradle §2 — R8

The Android developer pages "Enable app optimization" (last updated 2026-08-27) and the AGP 9.0.1 release notes (last
updated 2026-10-07), read in full as page text on 2026-10-08.

## 2.1 Enabling it
1. **Enable it on the release build,** not on tests or libraries. The page says optimization makes the build slower and
   debugging harder and recommends it only for the final build you test before publishing.
2. **Before AGP 9.3,** set `isMinifyEnabled = true` and `isShrinkResources = true` on the release type, and the page
   recommends enabling both. **From AGP 9.3,** `optimization { enable = true }` enables code and resource
   optimization and includes default Android keep rules equivalent to `proguard-android-optimize.txt`.
3. **With the 9.3 DSL, keep rules go in `.keep` files in `src/<variant>/keepRules`,** for example
   `src/main/keepRules/custom-rules.keep`. The source sets also work with the legacy DSL.
4. **Use `proguard-android-optimize.txt` in the legacy DSL.** The page says support for
   `getDefaultProguardFile("proguard-android.txt")` was dropped in AGP 9.0 because it contains `-dontoptimize`, which should
   be avoided; a global disable is done by adding the flag to your own file.
5. **R8 full mode has been the default since AGP 8.0** (opt-out `android.enableR8.fullMode=false`; the page tells you to
   remove that line). It makes stricter assumptions about reflection and dynamic features, so it can need extra keep
   rules.
6. **A keep file declared but missing fails the build** since AGP 9.0 (§1.4).
7. **Resource shrinking is optimised by default from AGP 9.0:** unreferenced code and resources are removed together;
   it needs the flag only on AGP 8.12 and 8.13.

## 2.2 Keep rules
1. **Refine keep rules to let R8 optimise as much as possible.** The page's tool for this is the R8 Configuration Analyzer,
   which finds the broadest rules and says what they prevent; it needs AGP 9.3.0-alpha05 or R8 9.3.7-dev. A separate
   Android skill (`r8-analyzer`) flags redundant, broad or subsumed rules.
2. **With AGP 9.0 a keep rule no longer applies to companion methods** that R8 synthesises when desugaring interface
   methods (a case that matters for libraries with `minSdk` below 24 compiled with `-applymapping`).
3. **With `strictFullModeForKeepRules` on (the 9.0 default),** `-keep class A` does not keep the default constructor;
   add the constructor to the rule if code creates the class reflectively.
4. **Kotlin null checks:** R8 by default rewrites them without their message (`remove_message`); the
   `-processkotlinnullchecks` option takes `keep`, `remove_message` or `remove`.
5. **R8 repackages classes by default from AGP 9.1,** which removes the need for `-repackageclasses`. **Global
   options such as `-dontobfuscate` in library consumer rules are ignored by apps from AGP 9.0.**
6. **Test the installed release build:** the page's fixes for breakage are to add keep rules, adopt optimisations
   incrementally and use libraries that suit optimisation. Retrace obfuscated stack traces with the mapping file.
